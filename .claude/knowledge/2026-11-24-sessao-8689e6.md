## decisao
- Liberar `git add -A` e `git commit -m "..."` só para o orquestrador em `.claude/hooks/orquestrador/guarda.mjs`, com regex que impedem encadear comandos e mantêm bloqueados push/reset/rebase/merge (por `_lib.mjs`), porque os agents não devem fazer commits e comandos destrutivos continuam perigosos para todos.

## padrao
- Usar `lint-staged` com função em vez de lista de arquivos: `"*.{ts,tsx,js,mjs,json,css}": () => "biome check --write --staged --no-errors-on-unmatched"` em `lint-staged.config.mjs`, permitindo que o próprio Biome encontre arquivos staged com `--staged`, evitando limite de linha de comando do Windows.

## nao-funcionou
- Passar lista de arquivos diretamente para o Biome no comando do pré-commit estoura o limite de linha de comando do Windows em projetos com 74+ arquivos; solução foi mover configuração para `lint-staged.config.mjs` e usar função que deixa o Biome encontrar arquivos por conta própria.
